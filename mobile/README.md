# تطبيق نقاطي للسائق — Flutter starter

هذه واجهة بداية. وظائف GPS الخلفية والإرسال إلى API ليست مفعلة بالكامل بعد.

## إعداد أولي
```bash
flutter create . --platforms=android,ios
flutter pub get
flutter run
```

## قبل تنفيذ التتبع
1. صمم شاشة شرح وموافقة/إقرار واضحة عن تتبع الرحلات.
2. اطلب صلاحيات الموقع المناسبة في Android وiOS، بما فيها صلاحيات الخلفية عند الحاجة.
3. Android: نفّذ خدمة foreground مناسبة مع إشعار دائم أثناء الرحلة، وراجع قيود إصدارات Android الحديثة وسياسات Google Play.
4. iOS: أضف إعدادات Background Modes وCore Location الملائمة، واختبر سلوك النظام عند تعليق التطبيق.
5. خزّن نقاط الرحلة محليًا في طابور مشفر/محمي وأرسلها على دفعات مع معرّفات تمنع التكرار.
6. لا تعتمد قراءة GPS إذا كانت الدقة ضعيفة أو كانت القفزة غير منطقية.
7. أوقف التتبع عند نهاية الرحلة وأظهر حالة التتبع بوضوح.

لا تضع أسرار الخادم أو مفاتيح إدارة قاعدة البيانات داخل تطبيق الهاتف.
