# متطلبات نقاطي — الإصدار الأول

## النطاق
- لوحة ويب عربية RTL لإدارة الشركات والسيارات والسائقين وقراءات العداد.
- تطبيق Flutter للسائق (Android/iOS) مع مسار تطوير GPS.
- API وقاعدة بيانات مستقلة.
- تكامل منصة ورشة مؤجل حتى توافر API موثقة وموافقة مالك المنصة.

## خارج نطاق النسخة الأولية
- احتساب مخالفات قانونية أو اتخاذ قرارات وظيفية آلية.
- ضمان تتبع 100% على جميع الأجهزة.
- التكامل المباشر مع wrshah دون توثيق ومفاتيح رسمية.
- دفع مكافآت مالية تلقائيًا.

## معايير القبول
1. يمكن إنشاء شركة وسيارة وسائق عبر API ولوحة الويب.
2. يمنع النظام تكرار رقم لوحة السيارة.
3. كل قراءة عداد تخزن بمصدرها ووقتها وسجل مستقل.
4. لا يقبل النظام قراءة يدوية أقل من القيمة الحالية إلا عبر مسار تصحيح مدقق يضاف لاحقًا.
5. واجهة الويب تعرض خطأ واضحًا عند انقطاع API.
6. تطبيق الهاتف يوضح أن GPS تقديري وليس بديلًا عن عداد السيارة الفعلي.
7. لا يجري تشغيل التتبع دون إفصاح وأذونات مناسبة.
8. يجب إضافة مصادقة وتفويض على مستوى الشركة قبل نشر أي بيانات فعلية.
