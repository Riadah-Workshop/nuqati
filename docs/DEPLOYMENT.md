# خطة النشر السحابي

## بيئات مقترحة
- Development: محليًا باستخدام SQLite.
- Staging: خدمة تطبيق + PostgreSQL مُدار + HTTPS.
- Production: خدمات سحابية داخل المملكة إذا كان ذلك مناسبًا للمتطلبات التنظيمية والعقدية.

## خطوات عامة
1. اختيار مزود سحابة وموقع استضافة مناسب.
2. إنشاء PostgreSQL مُدار، وتفعيل التشفير والنسخ الاحتياطي.
3. إعداد `DATABASE_URL` و`CORS_ORIGINS` عبر secrets/environment.
4. نشر FastAPI خلف HTTPS مع health check.
5. بناء واجهة الويب وضبط `VITE_API_BASE_URL` على عنوان API.
6. إعداد نطاق DNS وشهادة TLS.
7. إعداد المراقبة والتنبيهات والسجلات دون بيانات موقع حساسة.
8. تهيئة سياسة النسخ الاحتياطي والاستعادة.
9. إضافة المصادقة والتفويض واختبارهما قبل إدخال بيانات حقيقية.

لم تُنشأ موارد سحابية ولم يتم نشر النظام تلقائيًا؛ ذلك يتطلب حساب المزود والصلاحيات واختيار المنطقة والميزانية.
