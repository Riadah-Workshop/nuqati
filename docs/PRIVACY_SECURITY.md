# الخصوصية والأمن — قائمة تنفيذ

- الإفصاح بوضوح عن جمع الموقع أثناء الرحلة والغرض منه.
- طلب الأذونات النظامية؛ لا يوجد تتبع خفي.
- تقليل دقة/مدة الاحتفاظ بالموقع بما يناسب الغرض.
- تحديد سياسة احتفاظ وحذف ومراجعة قانونية محلية قبل الإطلاق.
- HTTPS فقط في الإنتاج.
- إدارة كلمات المرور باستخدام تجزئة قوية عبر مكتبة معتمدة؛ لا تخزن كلمات مرور صريحة.
- تطبيق RBAC وعزل بيانات كل شركة في الخادم، لا في الواجهة فقط.
- تدوير مفاتيح API وتخزينها في secrets manager أو متغيرات بيئة.
- تسجيل التعديلات الإدارية والوصول الحساس.
- نسخ احتياطي مشفر واختبار الاستعادة.
- إجراء اختبار اختراق ومراجعة اعتماديات قبل الإنتاج.
- لا تُرسل الإحداثيات إلى مزود خارجي إلا بعد تقييم الخصوصية والإفصاح المناسب.
