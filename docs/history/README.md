# Project history (patch notes & audits)

These are the delivery notes, test plans and audits written while Nuqati was built through
ZIP patches (Phases 1B–7 and the November 2026 updates). They are kept **unchanged** as a
record of *what was changed and why* and of the limits each patch declared.

> **Read them as history, not as instructions.** Paths and procedures inside them predate
> the repository clean-up ("Phase 0"):
>
> | Old path / habit in these notes | Today |
> |---|---|
> | `mobile/` | `driver_app/` |
> | `manager/` | `manager_app/` |
> | a file named `download` at the repository root | `.dockerignore` |
> | "replace `main.py` / `App.tsx` from this ZIP" | open a pull request (see `CONTRIBUTING.md`) |
> | notes at the repository root | this folder |
>
> For current procedures see `docs/DEVELOPMENT.md`, `docs/DEPLOY_COOLIFY.md` and
> `docs/ARCHITECTURE.md`.
